# 💎 Diamond Quality Check – February 2023 (Power BI)

## 📌 Project Overview
This Power BI dashboard analyzes **diamond quality check data for February 2023**.  
It provides insights into diamond distribution based on **color, clarity, cut, shape, and type**, helping in quality control and performance evaluation.

---

## 📊 Key Highlights
- **Total Diamonds Analyzed:** 499
- **Sarin Carats Grade:** F
- **Manager F/R:** F
- **Damage Status:** NA

---

## 🎛 Interactive Filters
The dashboard includes slicers for dynamic analysis:
- **Type:** A, B, C
- **Shape:** CMB, Cushion, Emerald
- **Color:** D, E, F
- **Cut:** EX, EXL, GD
- **Clarity:** I1, I2, IF

---

## 📈 Visualizations

### 🔹 Number of Diamonds by Color & Clarity
- Stacked bar chart showing diamond count across **GIA color grades** and **clarity levels**
- Helps identify quality concentration patterns

### 🔹 Number of Diamonds by Cut
- Pie chart representing distribution of cuts:
  - EXL
  - VG
  - EX
  - VG01
  - GD

### 🔹 Clarity by Shape
- Tree map showing **Signer Clarity distribution by diamond shape**
- Useful for shape-wise quality analysis

### 🔹 Detailed Data Table
Includes the following fields:
- Type
- Signer Color
- Shape
- Cut
- GIA Clarity
- Fluorescence
